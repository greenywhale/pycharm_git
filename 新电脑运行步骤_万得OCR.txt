【万得自绘目录 OCR 爬虫 - 新电脑运行说明】
更新时间：2026-03-04
适用脚本：万得自绘目录OCR爬虫.py

========================================
一、要拷贝到新电脑的文件
========================================
至少拷贝以下文件到同一目录：
1) 万得自绘目录OCR爬虫.py
2) （可选）查看控件结构.py

建议目录示例：
D:\wind_ocr\

========================================
二、新电脑前置环境
========================================
1) 安装 Python 3.10+（建议 3.11/3.12/3.13）
2) 安装依赖（在脚本目录执行）：

pip install pyautogui pillow pytesseract opencv-python numpy pandas openpyxl

3) 安装 Tesseract OCR（Windows）
- 推荐：
winget install --id UB-Mannheim.TesseractOCR --exact --source winget --accept-package-agreements --accept-source-agreements --silent

4) 检查 Tesseract 是否可用
- 常见路径：C:\Program Files\Tesseract-OCR\tesseract.exe
- 验证：
"C:\Program Files\Tesseract-OCR\tesseract.exe" --version

5) 安装中文语言包 chi_sim（详细步骤）
- 目标：让 `--list-langs` 里出现 `chi_sim`

方案A（有管理员权限，直接写 Program Files）
1. 打开 PowerShell（建议“以管理员身份运行”）
2. 执行：

Invoke-WebRequest -Uri "https://github.com/tesseract-ocr/tessdata_fast/raw/main/chi_sim.traineddata" -OutFile "C:\Program Files\Tesseract-OCR\tessdata\chi_sim.traineddata"

3. 验证：
"C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs

方案B（无管理员权限，推荐）
1. 打开普通 PowerShell
2. 逐行执行下面5行：

$td = "$env:LOCALAPPDATA\Tesseract-OCR\tessdata"
New-Item -ItemType Directory -Force -Path $td | Out-Null
Invoke-WebRequest -Uri "https://github.com/tesseract-ocr/tessdata_fast/raw/main/chi_sim.traineddata" -OutFile "$td\chi_sim.traineddata"
setx TESSDATA_PREFIX "$td"
$env:TESSDATA_PREFIX = "$td"

3. 验证：
"C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs

4. 预期结果至少包含：
chi_sim
eng
osd

如果没有看到 chi_sim：
- 先确认文件是否存在：
  Test-Path "$env:LOCALAPPDATA\Tesseract-OCR\tessdata\chi_sim.traineddata"
- 然后重新开一个新 PowerShell 窗口再执行 `--list-langs`

6) 运行脚本时建议显式指定 tesseract 路径
python ".\万得自绘目录OCR爬虫.py" --tesseract-cmd "C:\Program Files\Tesseract-OCR\tesseract.exe"

========================================
三、运行前操作（必须）
========================================
1) 打开万得客户端并登录
2) 进入“数据字典树形目录”页面
3) 关闭可能遮挡树区域的弹窗
4) 将脚本终端放在前台，便于交互选取截图区域

========================================
四、推荐运行命令
========================================
说明：以下命令为“慢速稳健版”，降低触发客户端异常概率。

PowerShell：
$env:TESSDATA_PREFIX="$env:LOCALAPPDATA\Tesseract-OCR\tessdata"
python ".\万得自绘目录OCR爬虫.py" --tesseract-cmd "C:\Program Files\Tesseract-OCR\tesseract.exe" --scroll-pixels 220 --scroll-wait 1.8 --expand-max-clicks-per-page 8 --expand-click-wait 0.3 --expand-after-page-wait 1.2 --mouse-safe-margin 40 --debug-dir ".\ocr_debug"

如果你确认可以自动尝试展开目录，再加：
--auto-expand

========================================
五、输出结果
========================================
默认输出文件：万得数据节点目录_爬取结果.xlsx
默认工作表名：外部数据目录

输出字段（7列）：
1) 序号
2) 节点编号
3) 节点名称
4) 父节点编号
5) 描述
6) 类型（0-数据源，1-目录，2-表）
7) 更新时间

========================================
六、常见问题与处理
========================================
问题1：报错 tesseract not found
处理：
- 确认 tesseract.exe 路径
- 命令中显式传 --tesseract-cmd
- 确认 TESSDATA_PREFIX 指向有 chi_sim 的 tessdata 目录

问题2：识别中文很差
处理：
- 必须安装 chi_sim
- 适当调低 --min-conf（例如 25）
- 增大截图区域高度，保证树文本清晰

问题3：触发客户端异常（疑似远程操控）
处理：
- 不加 --auto-expand
- 增大 --scroll-wait / --expand-click-wait
- 减少 --expand-max-clicks-per-page
- 必要时分批采集（缩小 max-pages）

问题4：程序中断，需要快速结束进程
PowerShell 执行：
Get-CimInstance Win32_Process |
Where-Object { $_.Name -eq 'python.exe' -and $_.CommandLine -like '*万得自绘目录OCR爬虫.py*' } |
ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
